宝可梦管理

会扫描队伍和 PC 盒子；改版的种族、技能、道具编号按原始 ID 保留。支持第 1–9 世代全国图鉴名称。
名称表：内置基础名称；正在尝试载入完整全世代名称表。
Mega 目录用于选择 Mega 对应的基础宝可梦。第四世代存档记录中没有已确认的独立 Mega 形态字段；ROM 中也尚未确认 Mega 石内部 ID 与 Mega 战斗机制。因此选择 Mega 喷火龙 X/Y 会添加基础喷火龙 #6，不会伪造形态编号或自动写入未经确认的道具 ID。只有游戏本身实现 Mega 机制并持有正确道具时，战斗中才可能 Mega 进化。
注意：宝可梦数据会重新计算 Gen IV 内部校验和；性格通过修改性格值实现。这个同人改版可能扩展了部分 ID，网页会保留并允许输入原始编号。由于存档本身不含改版 ROM 的全部基础种族值，直接新增到队伍时无法精确重算 HP 与战斗能力值缓存；更稳妥的做法是先新增到 PC 盒子，再从游戏内取出。修改后请先用备份验证。
